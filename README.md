# Odin Recursion

This is the eighth project assignment in the Odin Project Full Stack JavaScript lessons.

## Description

The project creates two cmd line apps:
1. Fibonacci Sequence (fibs.js)
2. Merge Sort (mergeSort.js)

First, run 'npm install', then run 'node fibs.js' or 'node mergeSort.js.
